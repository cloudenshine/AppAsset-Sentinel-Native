# 可交给 Codex 的整改任务与验收清单

基线：`f7c9dbf7a29b55cf7fa3d832bf3833ac67ee6e75`。本文件是后续实施输入，不是已实施结果，也不表示本次已经变更远程仓库。

## 实施目标

把当前原型收敛为可信的本地 AI 资产保全工具。保留技术栈和可复用扫描能力，以“真实状态 + 证据 + 可恢复操作”重构危险链路。首个可写生产适配器只做 Ollama 模型库，其余领域暂只读。

## 开工核对

先检查当前工作树、实际提交、用户修改和现有依赖；对照本次基线逐项复核，已修复的不得机械覆盖。不要修改全局 AGENTS.md，不改其他项目，不以用户重要目录作为故障注入对象。不得先执行现有整套测试再来修隔离，因为测试本身会触达真实用户设置。

不为这次整改重写语言、替换桌面框架、建设插件市场或引入微服务。先建立可验证的小执行核心。

## 执行包

### W01 / P0 / 关闭不可信写操作

关联 A01、A02、A06、A24。统一能力开关并作用于 API 及旧兼容路径。未实现功能返回明确不支持；simulation 的结构与状态不能冒充 live。去掉所有无实际证据的成功/可用状态。

验收：普通 UI、直接 API、兼容 API 都不能绕过；被禁止的调用前后用户文件/设置不变；失败不移除资产缓存或掩盖原因。

### W02 / P0 / 先隔离测试再运行测试

关联 A09、A27。存储根、环境变量读写、注册表操作、进程调用和文件系统操作的可替换边界按实际需要注入，不一次性抽象所有函数。默认单元测试不能写用户级 OLLAMA_MODELS、生产登记文件或重要注册项。原生集成测试只在显式配置的隔离账户/VM 中运行。

验收：测试前后无用户配置变化；无法创建 Junction 的用例明确 Fail 或说明原因的 Skip，不静默通过；污染防护用例本身可复现。

### W03 / P0 / 修复输入与授权边界

关联 A07、A08、A25。固定本地前端资源；改掉不可信元数据和路径插入 innerHTML/onclick 的路径；移除 PowerShell 代码字符串拼接。加入本地会话和合法请求来源检查。写接口只接受服务器存储的已授权计划身份，不能信任客户端返回完整计划。

验收：带单引号、双引号、反斜杠、中文、空格的合法数据往返一致；恶意 HTML 当文本显示；无效/过期/改动计划拒绝；未知调用方不能执行写操作。浏览器同源策略和 CORS 不是认证替代品。随机端口也不是认证。

### W04 / P1 / 建立真实未知状态与配置来源

关联 A13—A15、A17、A19、A22、A23。保留 evidence/source/time/confidence/completeness；Unknown 不猜成僵尸、NVMe 或无依赖。软件实例身份保留版本、架构、账户和可执行路径。注册表用 Hive/View/SubKey。有效配置优先于固定路径，用户磁盘偏好与硬件事实分开。

验收：同名多版本/内嵌运行时可区分；探测失败不生成伪造历史；规则错误保持前一有效快照；大小扫描不完整明确标识；32/64 注册表测试准确定位。

### W05 / P1 / 保留证据图，重新定义安全判定

关联 A15、A16。观察到的事实图允许有环；展示和计划用强连通分量、访问集合防循环，不丢弃证据边。版本和应用配置只能支持其实际证据范围，名称正则产生推测而非确认依赖。

验收：A→B→C→A 三条事实边全部存在，遍历终止；内嵌 Python 与外部指定 Python 的测试分开；Unknown 的依赖信息不能授权破坏性自动化。

### W06 / P0→P1 / 操作日志与统一写门控

关联 A03—A05、A11、A12、A18。计划记录精确目标、源/目标身份、需要保留的数据、旧配置、前置条件、状态与恢复材料。持久化写前日志；重叠资源互斥；幂等 task_id；每次切换前重验证。单机 SQLite 可用，但数据库提交不能代表文件系统迁移原子完成。

验收：每个关键步骤前后强制终止并重启，可由日志确定实际状态；不凭缓存“Completed”推断成功；登记失败/磁盘满/日志损坏不会继续删源；恢复不得误删不属于本任务的目标数据。

### W07 / P1 / 文件迁移内核

关联 A03—A06、A10—A12、A22。目标 staging 必须新建且受本任务控制；拒绝路径相同、包含、别名越界与不支持的文件系统语义。清单覆盖文件、目录、链接和所需元数据；复制后校验源稳定性、文件哈希和目标结构。冲突保留两份；取消不破坏既有资产。

验收：严格得到用户确认的 TargetPath；文件名相同内容不同不覆盖；目录/文件链接不默默丢失或展开；移除 Junction 不是恢复；源备份回收必须是单独且受授权的提交/保留期步骤；实际回收量来自卷空间证据并说明误差来源。

### W08 / P1 / Ollama 专用适配器与真应用验证

依赖 W01—W07。发现实例和有效 OLLAMA_MODELS；应用静默与维护窗口；保存旧配置；校验 manifests/blobs；优先官方配置重定位；消费端重新读取配置。Junction 仅作经过证据确认的兼容措施，而不是强制“双锁”。

验收：隔离 Windows 账户与两个测试卷上，已存在模型迁移后可列出并推理；配置重启后有效；受控写入落在目标；卸载/重装应用壳的测试不丢资产；切换后新数据发生时恢复策略仍保全新旧数据。

真实应用探针不得占用不受控费用或访问用户未授权内容。可用小型、合法可分发模型作为固定 fixture；不得把网络未能下载的测试伪装成通过。

### W09 / P1 / 漂移诊断与修复计划

依赖 W06—W08。比较真实路径、链接目标、有效环境配置和应用消费位置。先生成诊断：目标离线、路径替换、配置偏离、双边冲突等，原因未知时不杜撰“软件升级导致”。“修复”走独立授权计划和同一执行核心。

验收：任意两份不同内容都保全；离线磁盘不当作可删除残留；链接失败后还能恢复；注册状态可重建，不因无记录返回已健康。

### W10 / P1 / 第二适配器与只读扩展

完成首个适配器后再做 HF_HOME/HF_HUB_CACHE 的层级、缓存结构和链接适配。Docker、WSL、聊天库、活动视频工程先只读，暴露 unsupported 的写能力，而不是通用目录搬家。

验收：HF 有/无符号链接两种布局；共享 blob 不被错误计数或破坏；有效配置与缓存根一致；Docker 文件候选不会发送到目录迁移器。

### W11 / P2 / 简化界面与异步任务

依赖真实后端状态。首页回答需要关注什么、证据是什么、风险影响什么、可执行哪一项动作、有哪些恢复材料。详情展开代替每个资产一组大卡片。普通可读字号；路径可以复制；检查中、未知、已验证、需要注意清楚区分。

验收：先显示可用缓存、后台扫描不冻结操作；不依赖 800ms 固定延迟判断服务就绪；任务可观察/取消/恢复；真实 UI 操作路径与 API 断言一致；不得把样式截图当作功能验收。

### W12 / P1 / 可复现发布与受控 Agent 接入

先提供完整可运行分发 ZIP，不把单 EXE 当硬目标。当前官方 .NET 生命周期下，验证后升级 .NET 10 LTS，锁定构建版本并记录补丁。发布清单包括本地网页/规则/原生依赖、提交和校验值；检查 WebView2 和普通用户启动。支持只读 CLI，写接口等安全核心通过后开放。

验收：从公开 release 下载到与源码无关的空目录，普通账户、离线、中文/空格路径下完整启动；缺失依赖清楚报错；API/CLI/GUI/MCP 同一授权与执行政策。证明分发物和验收物一致，发布摘要区分 verified/not-run/unsupported。

## 发布门槛

R0 完成 W01—W03 及必要 W04 后只读发布；R1 完成 W04—W08 后只开放通过验收的 Ollama 操作；R2 完成 W09—W10 后按适配器分项开放；W11—W12 配合每次实际发布推进。不得用一项通过代表所有领域通过。

“有测试”不是标准：不丢未授权删除的数据、未执行不报成功、不确定不当事实、错误可恢复、发布物可独立运行，才是标准。
